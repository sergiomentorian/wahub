APIs do hub host + token de admin (config em runtime, sem rebuild)

Por padrão cada API usa a instalação da stack (.env) — sem regressão. Aqui você pode apontar qualquer uma para uma instalação externa (URL + token e, quando a API exige, os DSNs de banco/volume). A configuração é aplicada em runtime, persistida no broker (sobrevive a restart) e pode ser revertida com "Restaurar padrão".

Sobre o WA Hub broker de sessões WhatsApp

O broker fala só com a própria origem (zero CORS) e orquestra as APIs da stack: Evolution API e WAHA (família Baileys), Evolution Go, WuzAPI e UAZAPI (família whatsmeow).

A migração Tier 1 transfere a identidade do aparelho (o "passaporte") — o destino conecta sem re-parear; histórico e mídias re-sincronizam no destino. A Tier 2 (mesma família) copia também o store de chaves (migração quente).

A UAZAPI é destino-only: recebe migração, mas não pode ser origem.
